# Propuestas para Red Cóndor - Equipo 3: Hardware

**1. Botón de Pánico Robusto**  
Proponer el uso de un botón industrial de alto relieve o un interruptor de seguridad protegido. Debe ser operable fácilmente con las manos entumecidas por el frío, pero evitar falsas alarmas.

**2. Mantenimiento Modular**  
Diseñar el interior de las carcasas de forma que, si una batería o una antena se rompe, el equipo de la escuela pueda reemplazarla rápidamente sin tener que tirar todo el nodo.

**3. Test de Estanqueidad Escolar**  
Crear un protocolo de pruebas en el laboratorio del colegio: sumergir las cajas en agua helada para validar que no existan filtraciones antes de entregarlas a los puesteros.

**4. Indicadores LED de Estado**  
Incluir luces LED simples (verde para “conectado”, rojo para “batería baja”) para que el puestero sepa si su equipo está funcionando correctamente sin necesidad de mirar una pantalla compleja.

---

**Otras ideas recomendadas:**
- Usar conectores USB-C reforzados o pines de carga magnéticos.
- Elegir componentes que soporten bien el frío extremo (-20°C).
- Priorizar hardware fácil de conseguir o importar en lotes pequeños.
